# Javafirstapplication

A beginner-friendly **Spring Boot REST API** for managing students using **Spring Data JPA, Hibernate, and MySQL**.

## 🚀 Features

- Create a student
- Get all students
- Get a student by ID
- Update student details
- Change a student's ID
- Delete a student
- MySQL database persistence
- Spring Data JPA repository
- RESTful API endpoints

## 🛠️ Technologies Used

- Java 21
- Spring Boot
- Spring Web MVC
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Git & GitHub
